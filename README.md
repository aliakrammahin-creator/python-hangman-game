# Python Hangman Game

## About the Project

This is a simple Hangman game I built while learning Python. The game randomly selects a word, and the player tries to guess it one letter at a time before running out of lives.

## Features
- Random word selection
- Letter-by-letter guessing
- Tracks remaining lives
- Displays the correct letters and hidden letters
- Shows win and lose messages

## Technologies Used
- Python
- Random module

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Run `main.py` from your terminal.

## What I Learned

Through this project, I practised loops, conditional statements, lists, string manipulation, importing modules, and managing game logic.
